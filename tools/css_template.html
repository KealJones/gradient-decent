Gradient Decent / css

CSS

A tiny character-level language model whose entire forward pass is CSS colour math. Every activation is an rgb(), every weight block is a relative colour transform, every sum is a color-mix(). Trained on lowercase Shakespeare, 21K weights.

Hidden layer: 192 neurons as 64 colours

Logits: 36 characters as 12 colours

How it works

Weights are baked into the stylesheet as literals. Activations live in registered @property custom properties of syntax <color>, which Chrome stores as unclamped floats, so each color is a 3-lane vector register (alpha clamps to 0–1, so it's useless). A 3×3 block of a weight matrix is one color(from var(--x) srgb calc(r*a + g*b + b*c) …). Blocks are summed with a binary tree of color-mix() (which averages, so weights are pre-scaled by the leaf count). ReLU is max(r,0). The browser's style engine runs both layers in one style recalc.

JavaScript does three things: puts the last 8 characters into class names (the embedding lookup is CSS rules), reads 12 computed colors back, and samples one character. That's the clock tick.
